# 个人主页部署说明

这个文件夹已经是可部署版本。

## 直接本地打开

- 双击 `index.html`

## 部署到 GitHub Pages

- 上传整个文件夹中的全部内容到仓库根目录
- 确保仓库根目录包含 `index.html`
- 在 GitHub 仓库里开启 `Pages`
- 分支选择 `main`
- 文件夹选择 `/ (root)`

## 主要文件

- `index.html`：网站首页
- `assets/`：图片、脚本、PDF 等资源
- `project-coze-agent.html`：Coze 项目详情页
- `project-navi-badges.html`：NAVI 项目详情页
- `project-seed-eval.html`：Seed 项目详情页
- `publication-motivation-recognition.html`：科研详情页
